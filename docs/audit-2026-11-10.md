# Аудит @morze/ui 0.8.0 — спека

Дата: 2026-11-10. Нумерация — **A-xx**, чтобы не путать с ревью 2026-09
(D/G/V/K) и спекой erp-frontend (N).

## 1. Как проверяли

Три независимых прохода по дереву на коммите `9ecc7f3`:

1. **Компоненты** вне `data-table`, а также `form`, `lib`, `locales`,
   `theme-script`: корректность, a11y, controlled/uncontrolled, SSR.
2. **DataTable**: редактор ячеек, выбор строк, раскладка колонок, виртуализация,
   клавиатура, URL-состояние, a11y.
3. **Пакет**: `npm run build`, `publint`, `@arethetypeswrong/cli --pack`,
   `npm pack --dry-run`, публичный API против `src/components`, пробелы в
   наборе компонентов, тесты и CI.

Дефект попадает в спеку, только если он воспроизведён пробой (happy-dom или
настоящий Chrome через `vitest.browser.config.ts`) или однозначно следует из
кода. Всё, что уже описано в `FIXES.md`, `CHANGELOG.md` и прошлых спеках, не
повторяется.

Базовая линия: `typecheck` чистый, 517 unit- и 28 browser-тестов зелёные.

### Решения

- **A-01.** Одно сохранение за раз (ref-флаг), `readOnly` вместо `disabled`
  на время сохранения — фокус остаётся в поле, лишнего `blur` нет.
  Ответ, пришедший после размонтирования, игнорируется.
- **A-02.** Пока сохранение в полёте, закрытие списка — это сам выбор, а не
  отказ от правки: редактор ждёт ответа. Отказ снова открывает список с
  сообщением.
- **A-03.** Снятие галочки в режиме «все найденные» начинается с ключей
  текущей страницы минус снятая строка. Шапка страницы в этом режиме
  считается выбранной.
- **A-04.** «Откреплено» хранится как `false`, а читается обратно как
  `undefined`.
- **A-05.** Сохраняются и подмешиваются только ширины колонок из `sized` —
  тех, что пользователь изменил сам. Остальные берутся из объявления.
- **A-06.** Шапка использует тот же `pinStyle`, что и тело.
- **A-07.** Считаются только раскрытые ключи строк текущей страницы.
- **A-08.** Если строка с фокусом вне отрисованного окна, точкой табуляции
  становится первая отрисованная строка в той же колонке.
- **A-09.** Разобранный фильтр проверяется: простой объект, у каждой записи
  правильная форма; остальное отбрасывается — «нет фильтра», а не сломанная
  таблица.
- **A-10.** Пейджер показывает последнюю существующую страницу, а таблица
  сама уводит запрос на неё, когда `page > pages`.
- **A-11.** Поле поиска с черновиком — отдельный компонент; таблица
  перерисовывается только на отложенный коммит.
- **A-12.** `aria-selected` на строках в режиме `keyboard`/грида;
  `aria-level` на строках дерева.
- **A-13.** `editing` сбрасывается, когда его строки нет среди строк страницы.

### Решения

- **A-14.** Без `aria-label` на триггере: имя — из текста (дата или
  плейсхолдер) и связанного `<label>`. Новые пропсы `aria-label`,
  `aria-labelledby`, как у `Combobox`.
- **A-15.** `asChild` + `disabled`/`loading` ведёт себя как мягкое
  отключение: клик и Enter гасятся, `tabIndex` не трогаем.
- **A-16.** `inert` на панели, когда `offcanvas` свёрнут на десктопе.
- **A-17.** Один вызов `nudge` с множителем; `readOnly` отключает клавиши и
  кнопки.
- **A-18.** `value: Date | null` / `DateRange | null`; контролируемость —
  по `value !== undefined`, как у `Combobox`.
- **A-19.** `aria-label`/`aria-labelledby` передаются каждому ползунку; новый
  проп `thumbLabels` для диапазона.
- **A-20.** `aria-labelledby` на id подписи и значения вместо строкового
  `aria-label`.
- **A-21.** После очистки фокус возвращается на триггер.
- **A-22.** При `numberOfMonths > 1` дни соседних месяцев не попадают в
  табуляцию и не выбираются; `aria-selected` переезжает на `gridcell`.
- **A-23.** `FormControl` ставит `aria-invalid` только при ошибке; иначе —
  `undefined`.
- **A-24.** Клик/тап по «?» переключает подсказку (контролируемый `open`).
- **A-25.** Зеркало рисует счётчик; рефы объединяются.
- **A-26.** Home/End — только при пустом поле; отключённые пункты не
  подсвечиваются.
- **A-27.** «Ничего» не трогает отключённые опции.
- **A-28.** Ширина — детерминированная, от `useId()`.
- **A-29.** Новая подпись `common.breadcrumb` (en, ru) и проп `label`;
  `aria-current="page"` у активного пункта; кнопки пейджера мягко
  отключаются (`aria-disabled`), фокус не теряется.

## 5. Не входит в этот проход — бэклог

Найдено, но вынесено в следующие итерации:

- **Новые компоненты.** P1: `FileUpload`/дропзона, `TimePicker` и время в
  `DatePicker`, `TagInput` (создаваемые значения в `MultiSelect`). P2:
  `HoverCard`, `Resizable`, `InputOTP`, `ButtonGroup`, `Drawer` со свайпом.
  P3: `Toolbar`, `AspectRatio`, `VisuallyHidden`, `toast.promise`,
  `PasswordInput`.
- **`"use client"` на чистых хелперах** (`cn`, `buttonVariants`, хелперы
  запроса таблицы) — отдельная серверная точка входа `@morze/ui/utils`.
  Корневой реэкспорт `themeScript` — убрать в следующем minor с пометкой
  Breaking.
- **`/*#__PURE__*/`** на `icon()` и `cva()` — остаток при tree-shaking в
  esbuild/rollup.
- **Тесты** для компонентов без единой проверки: `Accordion`, `Badge`,
  `DropdownMenu`, `Kbd`, `Menubar`, `NavigationMenu`, `Popover`,
  `DateRangePicker`, `useSavedViews`.
- **README**: `ColumnManager`, `ColumnFilter`, `FilterChip`,
  `DataTablePagination`, `useIsMobile`.
- Подписи строк для чекбоксов и раскрытия (`rowLabel`), `treegrid` для
  дерева; `ChartContainer` под светлой вложенной темой.
